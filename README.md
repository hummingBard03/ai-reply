# クソリプほいほい 💬

投稿するとX風UIで20種のAIキャラクターがクソリプを返してくれるWebアプリ。
ランダムに選ばれた10キャラが1件ずつ、1回のAPIコールでまとめて返信する。

## 機能

- 各クソリプに **いいね / クソリプ返す / ブロック / Xシェア / 画像保存** ボタン
- **連鎖クソリプ**: リプライに対してさらに別の3キャラがクソリプを返す（無限連鎖可）
- **Xシェア**: ワンクリックでツイート投稿画面を開く
- **画像保存**: リプライカードをPNG（2x解像度）でダウンロード

## セットアップ

```bash
# 依存関係インストール
npm install

# 環境変数を設定
cp .env.example .env
# .env を編集して VITE_ANTHROPIC_API_KEY を設定

# 開発サーバー起動
npm run dev
```

`http://localhost:5173` を開く。

## 環境変数

| 変数名 | 説明 |
|--------|------|
| `VITE_ANTHROPIC_API_KEY` | Anthropic API キー |

## 技術スタック

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Anthropic Claude API (`claude-sonnet-4-6`)

## 注意事項

ブラウザから直接 Claude API を呼び出しています。本番公開する場合は APIキーが露出しないよう、サーバーサイドのプロキシ経由に変更してください。
