## キャラクター

| キャラ | 特徴 |
|--------|------|
| 🧠 意識高い系おじさん | 何でもビジネス・自己成長に結びつける |
| 🐻 おじさん構文おじさん | 絵文字多め、やたら馴れ馴れしい |
| 🪞 全部自分語りに変換する人 | 相手の話を即自分の話にすり替える |
| 🔬 謎の専門家 | 関係ない専門知識で煙に巻く |
| 🫂 やたら共感してくる人 | 内容無視で「わかる〜！！」 |

## セットアップ

```bash
# 依存関係インストール
npm install

# 環境変数を設定
cp .env.example .env
# .env を編集して VITE_ANTHROPIC_API_KEY を設定

# 開発サーバー起動
npm run dev
```

`http://localhost:5173` を開く。

## 環境変数

| 変数名 | 説明 |
|--------|------|
| `VITE_ANTHROPIC_API_KEY` | Anthropic API キー |

## 技術スタック

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Anthropic Claude API (`claude-sonnet-4-6`)

## 注意事項

現在の構成はブラウザから直接 Claude API を呼び出しています。本番公開する場合は APIキーが露出しないよう、サーバーサイドのプロキシ経由に変更してください。
